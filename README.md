# Krish Shah — personal website

A lightweight terminal-style personal website built for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `.nojekyll` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public website URL after the first deployment finishes.

## Edit the content

- Change the directory tree in `renderHome()` inside `script.js`.
- Change each text page in the `files` object inside `script.js`.
- Change colors and spacing in `styles.css`.
